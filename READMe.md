# コードの説明
## 実行方法

Pythonでそのまま実行するだけです。

```
python pipe_shape_optimizaion9.py
```

でいけます。


## パラメータ
PipeConfigで

- パイプの長さ
- くびれの開始点、終了点
- 最小点
- 入口流速等

もろもろ変更できます。

run_progressive_refinementでメッシュの細かさを変更できます。

最後のmainの実行中のOUT_DIRでデータ出力のディレクトリを指定。

## 流体計算
- 移流項は1次風上差分なので，数値粘性が非常に大きい。
- デフォルト設定ではレイノルズ数が高く，このコードではまともに計算できてないはずなので，レイノルズ数は下げて計算したほうが妥当。
- 直交座標と境界適合格子の両方が使えるようになっている。境界適合格子は，一般直交の格子（x,y座標。各セルが境界に沿うように変形している）を直交座標（ξ, η座標）に座標変換して計算している。
