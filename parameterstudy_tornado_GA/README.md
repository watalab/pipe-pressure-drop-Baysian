# コードの説明
## 概要
- 重陽子ビームによる熱伝導（熱条件）
- 斜面を流れる流体の連続の式（流体条件）
- 旋回流による力の釣り合い（力学条件）
などから、斜面を旋回流する液体リチウムが重陽子ビームの飛程以上の厚みを持ちつつ、熱負荷を除熱しながら、逆流することなく安定して流れるための条件をパラメータスタディを行う。
上記３つの条件について旋回流するリチウムのパラメータを用いて定式化を行い、条件を満たす液体リチウムのパラメータを「遺伝的アルゴリズム」を用いて導出する。
その後、OpenFOAMによるシミュレーションを用いて、その成立性を求める。
